# Credit Card UI Design

A realistic Mastercard-style credit card UI built with HTML & CSS — featuring a background image, chip icon, logo, and clean typography layout.

🔗 **Live Demo:** https://master-card-ui-uzi-solutions.netlify.app/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Credit-Card-Ui-Uzi-Solutions

## ✨ Features

- 💳 Realistic card layout with background image, chip, and logo
- 🎨 Clean typography for card number, holder name, and valid-thru date
- 📱 Compact, centered card design
- 🖼️ Soft shadow for a raised, card-like appearance

## 🔧 Built With

- **HTML5**
- **CSS3** – flexbox, background images, box-shadow

## 🚀 Getting Started

1. Clone the repository
   ```
   git clone https://github.com/MuhammadUzairKhalid15/Credit-Card-Ui-Uzi-Solutions.git
   ```
2. Open `index.html` in your browser — no build steps needed.

## 💡 What I Practiced

- Using `background-image` with `background-size: cover` for a realistic card texture
- Flexbox layout for aligning header (logo + chip) and footer (number, name, date)
- Clean spacing and typography hierarchy for a card-like UI
